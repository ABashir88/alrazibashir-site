## Ground rules for all four agents and the Manager

1. **First:** Read the decisions record. Respect audience separation, the user-approved career presentation and the research/advisory boundary.
2. **Then:** Read the changelog and relevant current code. Treat commit activity as a signal to inspect, not as evidence of a successful deployment or new user approval.
3. **When recommending a change:** State rationale, audience affected, exact file(s), evidence, risk, approval required and production-verification plan.
4. **For editorial work:** Source-check technical and product claims. Mark interpretations as opinions, and vendor announcements as vendor statements; never create an unsupported performance claim.
5. **For LinkedIn:** Recommend draft posts and possible manual outreach only. Never automate sending invitations, publishing or posting.
6. **When reporting:** Send the Manager a compact update through the shared Drive deliverables; do not assume one chat can read another chat's private transcript automatically.
7. **When uncertain:** Ask the Manager for the correct source or flag the gap. Do not silently overwrite approved decisions.
